# 08 — UI

## Stack

- **Next.js 14 App Router** with TypeScript
- **Tailwind CSS 3**
- **shadcn/ui** — owned components, copy-paste
- **lucide-react** — icons (shadcn default)
- **react-hook-form** + **zod** — for the dashboard forms (optional polish, plain useState works too)

## Reusable components

### `<Nav />` (`components/Nav.tsx`)

- Reads session from `authClient.useSession()`
- Shows user name + email + Logout button
- Logout → `authClient.signOut()` → redirect to `/login`

### `<DataTable columns rows onEdit onDelete />` (`components/DataTable.tsx`)

- Built on shadcn `<Table>`
- Props:
  - `columns: { key, header, render? }[]`
  - `rows: any[]`
  - `onEdit?: (row) => void`
  - `onDelete?: (row) => void`
- Renders table + per-row actions
- Empty state: friendly message ("No schedules yet — click Add to create one")

### `<FormModal title fields onSubmit />` (`components/FormModal.tsx`)

- Built on shadcn `<Dialog>`
- Props:
  - `title: string`
  - `fields: { name, label, type, options?, required? }[]`
  - `onSubmit: (values) => Promise<void>`
  - `initialValues?: object`
  - `trigger?: ReactNode`  (e.g. "Add Schedule" button)
- Handles loading + error state internally
- Toast on success/error

### `<ChatWindow />` (`components/ChatWindow.tsx`)

- Props: none (manages own state)
- State: `messages: { role, content, tool_calls? }[]`, `input: string`, `loading: boolean`
- Renders message list + input box + send button
- On submit: append user message → POST `/api/agent/chat` → append assistant message
- Auto-scroll to bottom on new message

### `<MessageBubble role content tool_calls? />` (`components/MessageBubble.tsx`)

- User: right-aligned, primary color
- Assistant: left-aligned, neutral, includes tool chips if any
- Tool chips: small `<Badge>` with tool name

### `/schedule`

- DataTable: Course | Title | Day | Time | Room | Instructor | Section | [Edit][Delete]
- Add button → modal with all fields
- Day is a `<Select>` (enum)
- Filter dropdown above table: by day / course / instructor

### `/rooms`

- DataTable: Room# | Type | Capacity | Equipment | Status | [Edit][Delete][View Bookings]
- Add modal
- Row click / "View Bookings" opens drawer/sheet with:
  - Bookings list (date, time, purpose, booked_by)
  - "Book Slot" button → mini-form
  - Conflict warning if overlap

### `/events`

- DataTable: Name | Date | Time | Venue | Organizer | Capacity (X/Y) | Status | [Edit][Delete][View]
- Add modal
- Row click → drawer with:
  - Description
  - Registrations list (name, student_id, registered_at)
  - "Register Me" button (uses current session)

### `/announcements`

- DataTable: Title | Priority (badge) | Posted | Expires | [Edit][Delete]
- Add modal (title, body, priority select, expires date)
- Body uses `<Textarea>`
- Priority badge color: high=red, medium=yellow, low=blue

### `/assignments`

- DataTable: Course | Title | Deadline | Status (badge) | Marks | [Edit][Delete]
- Add modal
- Status badge color: pending=yellow, submitted=blue, graded=green, late=red
- Filter by status

### `/agent`

- Chat window with welcome message ("Hi {name}! Ask me about schedules, rooms, events…")
- Input box at bottom
- Loading indicator during tool calls

## Toast

Global toast via shadcn's `useToast()`:

```ts
import { useToast } from "@/components/ui/use-toast"

const { toast } = useToast()
toast({ title: "Schedule created", description: "CSE 4113 added" })
toast({ title: "Failed to book room", description: "Time slot conflicts with an existing booking", variant: "destructive" })
```

## Risks / cuts

- Custom design polish (gradients, illustrations) — skip unless time
- Mobile responsive nav — defer to "open on desktop" README note
- Dark mode toggle — skip
- Search across all collections — skip (filter on each page is enough)
- Sortable columns — skip (filter is enough for demo data size)
